# 상태 블록 구간 지도

상태 블록은 전역 `0x4cc810`부터 3,692(`0xe6c`)바이트다. 세이브 파일은 이 블록에 체크섬과 바이트 뒤섞기를 한 것이고(`src/formats/saveFile.ts`), 전투 중 저장(continue data)은 실행 중 구조를 이 블록에 압축한 뒤 저장한다. 오프셋은 블록 시작 기준이다. "확인" 열은 원작 함수를 오라클로 실행해 검증했는지를 뜻한다(`pnpm oracle-check`).

## 유닛 압축 레코드 (36바이트)

`0x4071ea`가 실행 중 유닛 표(`0x478e10`, 108바이트 레코드)와 각 유닛의 위치 객체(유닛 +0x68이 가리키는 22바이트)에서 값을 옮겨 만든다. 이동 중인 유닛(`0x476b30`)은 위치 객체 대신 이동 전 위치(`0x476b90`)를 쓴다. 빈 칸(유닛 +0 의 0x8000 비트)은 건너뛴다.

| 오프셋 | 크기 | 출처 | 의미 |
|---|---|---|---|
| 0x00 | 1 | 위치 객체 +0x00 | x |
| 0x01 | 1 | 위치 객체 +0x01 | y |
| 0x02 | 1 | 위치 객체 +0x0a | 바라보는 방향 0~5(서, 북서, 북동, 동, 남동, 남서: 0x440567·0x417957·0x440bcd·0x410fda). 마스터는 맵 +0x64·+0x70에서 시작 |
| 0x03 | 1 | 위치 객체 +0x0b | 방향 × 3 + 애니메이션 프레임(0~2). 방향을 바꾸면 0x417957이 방향 부분을 고친다. 프레임 부분은 걷기 연출과 대기 애니메이션(0x412f6d, 옵션 0x503ff0 & 4에 따라)이 바꾸는 표시 값이다. `UnitRecord.pose` |
| 0x04 | 1 | 위치 객체 +0x12 | 애니메이션 카운터(0·2·4·6). 걷기 연출과 대기 애니메이션이 바꾸는 표시 값. `UnitRecord.animation` |
| 0x05 | 1 | — | 원작이 쓰지 않음 |
| 0x06 | 2 | 유닛 +0x02 | 유닛 종류: 마스터는 마스터 번호, 네이티얼은 네이티얼 표 번호(1~24). `re/tables.md` |
| 0x08 | 1 | 유닛 +0x04 (u16의 하위 바이트) | 진영(0/1). 되살릴 때 진영 레코드(0x45e0e8·0x45e0ec가 가리킴)의 번호로 쓴다 |
| 0x09 | 1 | 유닛 +0x09 | 소환 순번. MP가 모자라면 작은 순번부터 사라진다(0x4022d7). 마스터는 진영 번호 |
| 0x0a | 2 | — | 원작이 쓰지 않음 |
| 0x0c | 4 | 유닛 +0x2c | 레벨(0~2 = 레벨 1~3). 0x40fe72가 능력치 표의 칸으로 쓴다 |
| 0x10 | 4 | 유닛 +0x30 | HP. 소환·전투 시작 때 10(0x40f910, 0x40f521) |
| 0x14 | 4 | 유닛 +0x4c | OA(다음 차례까지 남은 시간). 시간 진행(0x4022d7)이 경과만큼 깎고, 행동 뒤 0x4113da로 다시 정한다 |
| 0x18 | 4 | 유닛 +0x50 | 상태 이상이 남은 분. 0보다 크면 시간 진행이 OA보다 먼저 깎고(0x4022d7), 차례 선택은 OA에 더한다(0x4129fb). 상태 마법이 정한다(0x40354b) |
| 0x1c | 4 | 유닛 +0x54 | 경험치. 100마다 레벨 +1, 최대 레벨이면 100에서 멈춤(0x412cc9). 한 번에 얻는 양은 0x412ca0이 줄인다. `UnitRecord.exp` |
| 0x20 | 2 | 유닛 +0x58 | 하위 3비트 = 상태 이상 1·2·4(행동 표 +0x07 세부의 0·1·2, 0x40354b). 위 시간이 다하면 지운다. 위 비트는 미해독 |
| 0x22 | 2 | — | 원작이 쓰지 않음 |
