# 전장 맵

## 로드 순서 (vmv2.exe 0x4224a0, 맵 번호 n)

1. 리소스 표 `0x460494[n]`의 ID로 DATA10 `MAP0nn._SC`(n = 0~51)를 맵 구조체(2,248바이트, `**0x48391c`)에 푼다(0x422479).
2. 0x4231af가 맵 +0x40으로 팔레트 분류 표(0x46205c, 색 번호 → 분류로 추정)를 정한다.
3. 맵 +0x18 → 배경 그림(`_BG`, `*0x483f48`), +0x1c → 팔레트(`_PL`, 0x483584), +0x20 → 부품(`_MP`, `**0x483918`), +0x24 → 격자(`_MD`, `**0x483554`)를 읽는다.
4. 부품 512개 중 +0x62가 12~15인 것은 +0x63의 0x80 비트를 세운다.
5. 격자를 작업용 사본(`**0x483560`)으로 그대로 복사한다. 전투 중 바뀌는 칸은 사본에서 바뀌는 것으로 추정한다.

코드는 `src/formats/mapData.ts`. 원작 로드를 오라클(`tools/oracle/boot.py`)로 맵 52개 모두 실행해, 맵 구조체·부품·격자가 TS 결과와 바이트 단위로 같음을 확인했다(`test/golden/mapLoad.json`).

## 맵 구조체 (`MAP0nn._SC`, 최대 884바이트)

원작은 맵을 읽을 때 구조체 꼬리를 지우지 않는다. 프로세스의 첫 로드에서는 0이지만 다른 맵을 읽은 뒤에는 앞 맵의 바이트가 남을 수 있다. TS(`loadMap`)는 늘 0으로 채운다(원작 첫 로드와 같음).

| 오프셋 | 크기 | 의미 | 근거 |
|---|---|---|---|
| 0x00 | 24 | 맵 이름(ASCII) | |
| 0x18 | 4 | 배경 그림 리소스 ID | 0x4224a0 |
| 0x1c | 4 | 팔레트 리소스 ID | 0x4224a0 |
| 0x20 | 4 | 부품 리소스 ID | 0x4224a0 |
| 0x24 | 4 | 격자 리소스 ID | 0x4224a0 |
| 0x28 | 2 × 3 | 미해독(예: Silent Hill 6, 11, 11) | |
| 0x34 | 4 | 0이 아니면 시각에 따라 밝기가 바뀜 | 0x402272, "Bright Change" 0x468c4c |
| 0x38 | 4 | 고정 밝기(실제 맵에는 0과 2만 있다) | 0x402272, "Always blurry/bright/dark" 0x468b84 |
| 0x3c | 4 | 전투 시작 시각(분). 새 전투가 0x40224d로 하루 중 시각에 넣는다 | 0x4017a2, 0x401b12 |
| 0x40 | 4 | 팔레트 분류 표(0x46205c) 설정 값(색 번호 → 분류로 추정) | 0x4231af |
| 0x74 | 4 | 적 마스터 설정 리소스 ID(DATA10 `MAS0xx._SC`) | 0x42d2e9 |

## 부품과 격자

- 부품(`_MP`): 100바이트 × 512개(51,200바이트). +0x62 = 종류(12~15는 특별 취급), +0x63 = 플래그. 나머지 미해독.
- 격자(`_MD`): 32 × 32 칸의 u16 부품 번호(행 우선, 2,048바이트).

## 적 마스터 설정 (`MAS000~037._SC`, 448바이트)

마스터 이름·설명 문자열 뒤에 숫자가 있다. 0x42d2e9가 진영 레코드로 복사한다: 데이터[5] = 마스터 번호, 데이터[6] = 레벨, 데이터[7..]은 0x424fbf, 데이터[0x51..](-1로 끝)는 0x42d64f(소환 가능 네이티얼로 추정)로 넘긴다.

## 게임 메모리 덩어리 (0x42dc10)

`GlobalAlloc(0x42, 0x7500f0)` 하나를 잡아 고정 위치로 나눈다. 기준 B에서: +0x60000 → 0x483f3c, +0x93220 → 0x483f0c, +0x14a000 → 0x483f34, +0x1a2000 → 0x483f38, +0x1aceb0 → 0x483f48(배경 그림), +0x4cb1b0 → 0x483f44, +0x62f2b0 → 0x483f18(맵 구조체), +0x62fb78 → 0x483f14(부품), +0x63c378 → 0x483f4c, +0x63cb78 → 0x483f04, +0x63d378 → 0x483f1c, +0x63d870 → 0x483f28, +0x651870 → 0x483f2c, +0x6540f0 → 0x483f30, +0x6600f0 → 0x483f20, +0x7200f0 → 0x483f00(DAT 읽기 임시 버퍼). B 자체 → 0x483f08·0x483f10·0x483f24.
