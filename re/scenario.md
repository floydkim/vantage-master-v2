# 시나리오·Expert 모드 흐름

해독: ⑤a. 코드 `src/engine/scenario.ts`, 픽스처 `scenarioFlow.json`(`pnpm oracle scenario_flow`).

## 진입

- 타이틀 Scenario → Select Level(0x83) → `*0x5061cc` = 0 Easy·1 Normal(0x426a3a) → 0x450da0:
  - 블록 +0x8(`*0x5061d8`) = 1, +0x10(`*0x5061d4`) = 0
  - 맵 플래그 +0x198(0x475b98 → 0x4cc9a8): 52개를 0으로, 첫 묶음(맵 0~3)을 1로
  - 진영 상태 0 조종 0(사람), 1은 1(CPU)
  - 0x426d90(Master making 창, ⑤b)
- 타이틀 Expert → 0x450e35: +0xc = 2, 맵 30(첫 묶음)만 1. 나머지는 같다.

## 우리 진영(0x42d190, Master making이 부름)

- 이름: Master making에서 넣은 글자(0x483efc)
- 표준 이름 +0x14 = 0, 마스터 = 인자(원작은 0x465f34[선택])
- 레벨: 시나리오 0, Expert 22. 능력치는 0x42dae0
- 목록: 비운 뒤 시나리오는 네이티얼 1·7·13·22, Expert는 마법 10~15·네이티얼 1~24

## 적 진영(0x42d2e9, 맵을 고를 때 0x4514a2·되살리기 0x401899)

- 맵 +0x74의 `MAS0xx._SC`: [0~4] 이름, [5] 마스터, [6] 레벨, [7…] 설명(→ 0x483bec), [0x51…] 아이템(−1까지)
- Easy는 레벨을 (max(레벨 − 7, 0) × 17 + 5) / 22로 낮춘다
- 아이템(0x42d64f): 표 0x468d60[아이템] = (종류 1이면 네이티얼, 아니면 마법, 번호). 목록은 오름차순 자리에 넣고 같은 값도 넣는다(0x42d7d0·0x42d966)

## 전투 뒤(0x408034 → 0x45157b)

- 결과 창(0x407d43 → 0x4080ac): 시나리오(+0x8)에서 이기면(0x476b6c) 0x408447이 진영 0 레코드를 복사해 레벨 + 1로 다시 계산한다(0x42dae0). 레벨 + 1 < 40이면 마지막 쪽이 5다(아니면 4).
  - 쪽 5(0x409c6d, 바탕 DATA00 0x24): 레벨(1부터)과 능력치 7가지(+0xa4~+0xbc)의 전(x 272)·후(x 308)를 y 60부터 20씩 그린다. 오른 값은 색 0x7b다.
  - 보상(+0x18 = 0x42da6c(고른 맵 +0x2d4))이 −1이 아니면 아이템 그림(칩 2 × 6, (48, 240))·"%s is acquired."(아이템 이름, (112, 240))·설명((112, 260), 줄바꿈마다 20줄 아래)을 그린다.
  - 진행(0x45157b)은 END에서 따로 한다. 쪽 5는 보이기만 한다.
- 타이틀로 갈 때: 월드(0x451bbb(1))는 시나리오면 0x42e92b(대화 상자 0x84, "Do you wish to save the game data?")를 띄운다. Save는 게임 데이터 저장(0x441aea)이고 저장해야 떠난다. Surrender는 떠나고 Cancel은 남는다. 결과 창(0x407ff9(1))은 시나리오면 예/아니오 "Do you wish to abbandon the game?"를 묻는다.
- 되살리기(0x401899)는 시나리오면 0x42d2e9(1)로 진영 1을 고른 맵의 MAS로 다시 채운다(오라클 확인). 시나리오에서 진영 1은 편집할 수 없어 블록 값과 같으므로 리메이크는 블록 값을 그대로 쓴다.

- 통계 누적(0x41bd98): 블록 +0xd78 59칸 += (0x476bd0 첫 칸, 진영 상태 0 +0xc − 2, 진영 0 전투 통계 57칸). 0x41bce9가 비운다(0x450f4e·월드 시작 0x45102d. 0x45102d는 Master making 끝 0x42749c·Free Battle 0x450f45에서도).
- 진행(0x45157b):
  - 고른 맵을 2로 둔다.
  - 묶음을 차례로 연다. 시나리오 [4, 4, 5, 5, 8, 1, 1, 1, 1](0x475b9c), Expert [1 × 8](0x475bc0, 맵 30부터).
  - 깬 맵이 (크기 + 1) / 2보다 적은 묶음에서 멈춘다.
  - 0x42da93: 우리 마스터 레벨 + 1, 능력치, 보상 아이템 0x468f40[맵](맵 0~25).
  - 깬 맵은 다시 싸울 수 없다. 고를 수는 있지만 맵 정보의 READY는 깬 맵이면 눌러도 아무 일이 없다(0x42aa8f가 +0x10 = 플래그 ≠ 2일 때만 0x45042d). ⑤a에서 '깬 맵을 다시 고를 수 있어 레벨에 상한이 없고 보상이 겹친다'고 본 것은 틀렸다(⑤d 리뷰가 오라클로 확인).
    - 그래도 0x42dae0은 평탄한 행 (마스터 × 40 + 레벨)을 읽는다(`readMasterStats`). 시작 레벨 + 깬 맵 수가 39를 넘는 일은 없다.
    - 보상은 첫 완주로 네이티얼 24·마법 6이 꽉 차고 겹치지 않는다. 꽉 차면 넣지 않는 막음(`insert`)은 도달하지 않는 방어다.
  - 장면:
    - 시나리오에서 새 묶음 1~5가 열리면 0~4
    - 그 밖에는 맵 26이면 5, 멈췄으면 −1, 다 깼으면 6
  - Expert는 마지막 맵까지 −1, 끝에 6.
- 장면 종류는 장면 창(CEndingWnd, ⑤c)의 스크립트를 고른다. 0~5는 DATA08 항목 0~5, 6은 DATA09 ED 엔딩(0x460180[진영 레코드 +0x9c 마스터]).
