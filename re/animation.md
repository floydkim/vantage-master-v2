# 전장 연출 (vmv2.exe)

연출 틀은 `src/ui/battle/stage.ts`(Stage), 위치 도우미는 `src/ui/battle/place.ts`. 오라클 픽스처 `test/golden/walk.json`(생성기 `tools/oracle/gen_walk.py`)이 틱마다 표시 객체 풀·타이머 카운터·단계를 담는다.

## 타이머 0x403020 (48ms)

1. 시간 제한(0x407926, 자유 모드는 없음). 일시 정지(0x45e0e4)가 아니면:
2. 옵션(0x503ff0) & 1이면 하늘 한 단계(0x43d535).
3. 0x476b20 += 1. 2가 아니면 0x412f6d(0, 0). 2면 0으로 두고 커서 프레임 0x476ad4 = (+1, 4 넘으면 0), 커서가 켜져 있으면(0x476bac) 커서 자세 = 13 + 프레임. 0x476ba8 += 1. 2가 아니면 0x412f6d(1, 0). 2면 0으로 두고 옵션 & 2면 물 프레임 0x49de20 = (+1) % 4, 옵션 & 6이면 상태 창 그림(0x40aff3 → 0x40b47d → 0x40c969), 0x412f6d(1, 1).
4. 0x412f6d가 1이면 이어 하기 0x476b2c. 팔레트 번쩍임(0x41b421), 바뀐 칩 그리기(0x43e578), 네트워크(0x406560).

카운터 0x476b20·0x476ba8은 전투 시작(0x401b12)에만 0. 커서 프레임은 커서 칸이 바뀌면(0x403d7b) 0, 그때 커서 자세 0xd.
애니메이션 옵션 기본값 0x77(레지스트리 'SaveDataKey'가 없을 때 0x44e181). 화면은 비트 1(하늘)·2(물)·4(대기·덧그림)만 읽는다.

## 틱 처리 0x412f6d(p1, p2)

- 연출 객체(0x47a3a8부터 0x7c바이트, 최대 0x40, 개수 0x47a3a4): 이번 틱 처리 표시(+0x28 & 2)를 모두 지우고, 끝나지 않았고(+0x28 & 0x80000000) 처리하지 않은 첫 객체의 처리기(+0)를 p2, 또는 p1이고 +0x28 & 0x10 = 0, 또는 +0x28 & 0x18 = 0이면 부른 뒤 처음부터 다시 훑는다.
- 표시 객체(풀 0x47c2b0, 0x16바이트, 빈 칸 +0x13 & 0x80) 종류(+0x11)별:
  - 1 대기: p2이고 (옵션 & 4 또는 (+0x12 >> 1) 짝수)면 +0x12 += 2(8이면 0), 자세 = 방향 × 3 + 프레임(+0x12 >> 1, 3이면 1).
  - 2 튀어 오름: 틱마다 높이 10, 7, 4, 2, 1, −1, −1, −2(0x417795), 0x1c째에 지움.
  - 3 표식 돌기: p1마다 +0x12·자세 += 1, 8이면 자세 −= 8.
  - 4 상대 차례 표식: p1마다 0x4136da(난수로 자세 고름).
  - 5 범위 표식 흔들기: p2마다 +0x12 = (+1) & 3, 0·3이면 자세 − 1, 1·2면 + 1.
  - 6 차례 유닛: p1마다 색 바꿈 선택 위 두 비트 = (0, 0x40, 0x80, 0x40)[+0x12 & 3], +0x12 += 1(8이면 0), 프레임은 종류 1처럼.
  - 덧그림(+0x14 ≠ 0): p2이고 옵션 & 4면 +0x15 = (+1) & 3.
- 살아 있던 연출 객체가 이 틱에 모두 끝났으면 개수를 0으로 두고 1, 아니면 0.
- 연출 객체 할당 0x412ed3: 첫 끝난 칸(없으면 끝). 초기화 0x412de9([8]·[9] = −1, +0x28 = 0). 끝 0x412f56.

## 표시 객체 풀 조작

- 할당 0x4174a6: 첫 빈 칸(없으면 끝, 최대 0x200), 0x41743f가 +4~+7·+0xa·+0xb·+0xe~+0x15를 0, +0x13 = 4로(칸 좌표·칩 좌표·높이·페이지는 남는다). 지움 0x41752e: +0x13 | 0x80.
- 칸에 세움 0x417542: 높이 = 부품 +0x61, 칩 x = (y & 1) + 2x, 칩 y = 2y + 0x17 − 높이, 어긋남·들림 0. 방향 0x417957: 자세 = 방향 × 3 + 자세 % 3. 모습 0x412b50: 상태 이상 비트 1·2·4 → 종류 0·색 바꿈 8·4·2·덧그림 1·2·3, 없으면 종류 1·0·0.
- 커서 0x4021ee(전투 시작, 유닛 다음 칸): 자세 0xd, 페이지 0x2c6, 묶음 1, 플래그 6. 칸 0x403c8e(들림 0xc), 켬 0x403b10(끄거나 칸이 없으면 플래그 | 2), 마우스 0x403d7b.
- 차례 표식 0x40574a / 지움 0x40583f(유닛 종류 1, 색 바꿈 & 0x3f, 플래그 & ~8: 모습 0x412b50이 아님), 범위 표식 0x4058b6 / 지움 0x405a1c(re/ui-input.md 화면 표시).

## 걷기 0x41377b(유닛, x, y)

정렬 키 1, 종류 0. 연출 객체 처리기 0x415829(이동 타입 4면 0x415a11, +0x3c = 경로 칸 높이 최대 0x440ca4 + 4), +4 유닛, +0x10 표시 객체, +0x20·+0x24 목표 칸. 처리기는 틱마다(플래그 0):

- 0x415829: 표시 객체를 복사해 지금 칸에 세우고(0x417542), 0x440bcd로 다음 칸·방향에 세운다. +0x2c += 1이 6 미만이면 칸을 지금 칸으로 되돌리고(다음 칸이 낮으면 높이를 지금 칸 높이로), 0x4177ee(방향 × 60°, (+0x2c × 48) / 6 − 48)로 물러선다. 6이면 미니맵(0x40d977), 목표 칸이면 0x412b50·키 0·끝, +0x2c = 0. +0x30이 2가 될 때마다 걷기 프레임(종류 1 대기와 같은 식).
- 0x415a11: 그림자 켬(+0x13 & ~4). 단계 +0x34 0: 틱마다 한 층 떠올라 +0x3c에 닿으면 단계 1로 바로 이동. 1: 0x415829처럼 한 칸 가되 높이는 +0x3c, 지형 종류 0xb 칸 위면 그림자 끔(+0x13 | 4), 목표 칸에 닿으면 단계 2. 2: 틱마다 한 층 내려와 칸 높이면 0x417542·0x412b50·키 0·끝.
- 사람 이동 0x406c5b(x, y, 이어 하기): 제자리면 이어 하기를 바로, 아니면 0x476b2c = 이어 하기(0x405fba → 단계 3), 단계 0, 걷기. CPU는 생각(0x445b20)이 결정 처리 0x406573을 부른다: 차례 표식 지움(0x40583f), 단계 0, 표시 객체 사본(0x476b90), 도착 칸 상자(0x40646b, 반경 = 명령 종류 ≠ 0)가 창 밖이면(0x406ad9) 반경 2 상자를 보이게 화면 이동(0x406b3a → 0x4147b3, 연출 객체) 뒤 이어 하기 0x40672d(이동 범위 0x4404c9 → 0x406c5b, 이어 하기 0x4067b1 → 명령).

## 위치 도우미

- 0x417730: 3차원 x = 칩 x × 24 + 어긋남 x, y = (칩 y − 0x17 + 그릴 높이) × 12 + 들림, z = 그릴 높이 × 12 − 어긋남 y + 들림.
- 0x4175dd(x, y, z, 들어 올림): 칩 x = (x + 0x1800) / 24, 칩 y = (y − z + 0xd14) / 12, 그릴 높이 = (z + 0xc00) / 12, 나머지가 어긋남·들림. 들림 < 어긋남 y면 높이 + 1. 들어 올림이고 높이 ≤ 칸 높이, 들림 > 0, 부품 +0x60 ≤ +0x61이면 높이 + 1·들림 − 12.
- 0x417795(dx, dy, dz): 0x417730 → 더함 → 0x4175dd(들어 올림).
- 0x4177ee(각, 거리): dx = −cos(각 × 3.14159 / 180) × 거리, dy = −sin(…) × 거리 / 1.73205, 각각 0에서 멀어지게 0.5를 더해 버림(x87, 0x45b410·0x45b408·0x45b3f8·0x45b400) → 0x417795.

## 공격 연출 (③b-3b, `src/ui/battle/attack.ts`, 픽스처 `test/golden/attack.json`)

- 명령 실행 0x406d13 종류 1: 0x40583f·단계 0, 0x476b2c = 0x406045, 0x413820 → 0x45f8d0[행동 +0xc](0 공격 0x413852, 1~3 마법 ③b-3c), 0x402954(번쩍임 지움 0x41b117, 어두운 칸 0x76~0xe5 = 6~0x75 사본). CPU는 걸은 뒤 0x4067b1이 명령 방향(0x417957), 대상이 주체 칸이 아니면 대상 칸에 커서(0x403c8e → 상태 창 0x40aefd)와 화면 확인(0x406ad9(대상, 효과 반경) → 0x406b3a(반경 + 1)).
- 0x413852: 연출 객체 E(처리기 0x414939)를 먼저 할당. 주체가 대상 쪽으로(0x41798c), 자세 = 방향 × 3 + 1, 종류 0, E +0x4c = 방향 × 60, +0x50 = 0x417730(주체). E +8 = 주체 사본(자세 방향 × 3, 키 2, 페이지 0x2c6, 묶음 6, +0x12 0, 플래그 2), +0xc = 그 사본(키 1), +0x10 = 주체. 공격 그림 0x46089c[그림 × 2 + 진영] → 페이지 0x2c6(표식 그림 자리, 차례 입력 시작 0x40546d → 0x422f9a가 다시 읽음), 배치 0x460a34 → 묶음 6, 스크립트 0x460bcc[그림](앞의 0x33은 0x4157bf가 건너뜀). 범위 종류 1이면 투사체 객체 P(0x416929): 주체 사본(페이지 0x2f3, 묶음 8, 플래그 6), +0x3c = 행동 +0xb, 0x416bd3이 정한 각으로 그림 0x46163c[그림] + 진영 × 0x30 + ((각 + 15)/30 mod 12) × 4·배치 0x461bf4 → 묶음 8.
- 스크립트 해석기 0x414939: 위 r_scr 메모. 0x27~0x2a 팔레트 번쩍임 0x41b284(r, g, b, 알파, 걸음, 범위) — 칸마다 섞임 색(지금 색을 접어 둠)에서 목표로 t를 256에서 걸음씩 줄이며, 0x41b421이 틱마다(이어 하기 뒤) 기본 색과 알파로 섞어 0x482a0c에 쓴다.
- 투사체 0x416bd3(float32 저장, x87 53비트): A = arc², dx = (대상 칩 x − 사본 칩 x) × 24, dy = trunc((대상 y − 사본 y) × 24 × 1.73205f), dh = (대상 칸 높이 − 사본 그릴 높이) × 12, r² = dx² + dy². B = dh² + r², C = A − 1.2·dh, E = (A − 1.2·dh)·C − 1.44·B, E < 0이면 A = √B·1.2 + 1.2·dh로 다시. K = (√E + C)·r² / (2B), 속도 x·y = ±√(d·K·d / r²), z = √(A − K)(r² < −2·dh·A/1.2면 음수). 0x416ea6(n): 기준점 + n·속도, z에 −1.2·n²/2, 0x4175dd(들어 올림 없이), 기울기 (vz − 1.2n)/√K로 자세 0~16, 닿음 = r² < n·K·n. 스크립트 0x25 신호를 기다렸다가 보이고 걸음마다 자세 ^ 1, 닿으면 지우고 0x40354b(대상 칸, 새로 계산, 전부).
- 타격 0x40354b의 보이는 부분: 몫 타격이 아니면 데미지 숫자 0x412c14(첫 빈 칸, 칩 좌표 = 대상, 높이 0x28, 자세 = min(|데미지|, 10), 페이지 0, 묶음 1, 종류 2, 회복이면 색 바꿈 0x20; 틱마다 높이 10, 7, 4, 2, 1, −1, −1, −2 뒤 0x1c째에 지움). 반응 종류: 행동 종류 1(회복) 2, 범위 종류 1·2 1, 몫 타격 1, 나머지 0. 각: 원점(효과 반경 0이면 주체 칸, 아니면 지정 칸)이 대상 칸이면 대상 방향 × 60, 아니면 0x417af7(float32: 180 − acos(x/√(x² + y²))·180/3.14159, y = 칸 y 차 × 24 × 1.73205f, y > 0이면 360 −) 버림. 반응 0x41452e: 대상의 반응 객체(+0x28 & 4)가 있으면 스크립트·기준점만 바꾸고, 없으면 새로(대상 종류 0, 각). 몫 타격이 아니고 네이티얼 HP가 0이면 +0x48 = 0x4160e3(0x32에서: 0x412b50, 소멸 0x41461a, 유닛·+0x10을 비우고 다음 명령으로). 마스터가 쓰러지면 0x476b28 = 1(연출 없음).
- 소멸 0x41461a: 네이티얼(유닛 +0 & 0x4000)은 스크립트 0x45fcfc(가림 무늬 1~7 뒤 숨김, 플래그 0x10 = 4틱마다). 마스터는 0x416129(본문 위 메모: 돌기 → 사본 → 떠오르며 가림 무늬), 그림 0x461eac·배치 0x461f84[마스터 × 2 + 진영] → 페이지 0x2c6 + 진영 × 0x1e, 묶음 6 + 진영.

## 마법 연출 (③b-3c, `src/ui/battle/attack.ts`, 픽스처 `test/golden/magic.json`)

- 대상 칸 효과 0x413c45(주체, 행동, 칸): 연출 객체 M(스크립트 0x4612b4[행동], +0x3c 행동, +0x20 칸)을 먼저 할당. +8 = 칸에 세운 그림(키 −2, 페이지 0x2d5, 묶음 7, 플래그 6), +0xc = 그 사본(자세 + 1), 그림 0x461094·배치 0x4611a4[행동 × 2 + 진영]. +0x14 = +8 사본(페이지 0x2f3, 묶음 8, 키 −1; 그림 표 0x483924·0x483a34는 bss라 읽지 않음).
- 시전 0x4141fd(주체, 대상 객체): 공격 0x413852와 같은 꼴(사본 키 2·1)에 시전 그림 0x460c98·배치 0x460e30[그림 × 2 + 진영]·스크립트 0x460fc8[그림], +0x38 = 대상 객체. 시전 스크립트의 0x25가 대상 객체를 깨우고, 대상 객체 스크립트는 0x26으로 기다린다.
- 연출 번호 1(0x413b12): M(대상 칸) + 시전. 2(0x413b45): M을 주체 칸에(대상은 그대로), M +0x18·+0x1c = 대상 칸 그림(키 −2·−1), 시전은 0x414397 → 0x415e18(스크립트 없이 2틱마다: 몸 사본 자세 흔들기, 모으기 그림 0x30094·0x30095(페이지 0x2f3 키 3)를 보이고 자세 3번 +1, 몸 숨기고 사본 보이기, 두 틱 쉬고 M을 깨운 뒤 M의 0x25 신호를 기다려 몸을 보이고 끝). 3(0x413e7c): 마법 투사체 0x416a4d(주체 사본, 페이지 0x2f3 묶음 8, 그림 0x461828·배치 0x461de0[그림] + 진영 × 0x30 + 각 칸)를 먼저, 이어 시전(+0x38 = 투사체), M(대상 칸). 투사체는 범위 종류 1이면 포물선(0x416bd3·0x416ea6), 아니면 직선 0x4170ae(K = r²·arc² / (dh² + r²), 속도 √, z 부호 = dh, 자세 = 기울기 dh/√r² 표)·0x417372(z = n·vz + 기준점), 걸음마다 그 자리에 자취 0x413fde(스크립트 0x45f97c, 키 −2 페이지 0x2d5 묶음 7), 닿으면 M을 깨운다.
- 둘레 타격 0x2e·0x2f: 거리 ≤ 행동 효과 반경이면 0x440dba 차례 칸마다 0x40354b. 지정 칸이 아닌 칸이 원점(효과 반경 0이면 주체 칸, 아니면 지정 칸)에서 효과 반경·여유 1·유닛 무시 직선 시야(0x41090b)로 보이고 0x410eda(지형 0x10 가림, 0xb 안 가림, 그 밖은 칸 높이 > 원점 높이)가 아니거나, 효과 범위 안이면 불꽃 0x413ddb(스크립트 0x45f94c, 플래그 8 = 2틱마다, 칸 위 원점 높이).
- 특수 0x2b(0x403aaa): Bless(종류 5) 0x412d32 — 주체 진영 네이티얼마다 HP +1과 회복 숫자 1. 물높이(종류 4) 0x42562e(단계·남은 분, 0x417bed: 그림자 있는 표시 객체를 다시 세움) → 지형 겹 목록 다시 짓기(0x43b8a8). 범위 종류 5 물높이 마법의 물높이와 작업 격자는 명령 실행 때(0x4255d0·0x4255ff → 0x4071bd) 이미 바뀐다.

## 차례 흐름 (③b-3d, `src/ui/battle/flow.ts`, 픽스처 `test/golden/turn.json`)

이어 하기 0x476b2c가 단계를 잇는다: 연출 객체가 모두 끝난 틱에 다음 단계를 부르고, 그 단계가 같은 틱에 새 연출 객체를 건다. 엔진은 차례 전체를 한 번에 적용하며 단계 기록(`TurnStep`)을 남기고, 흐름은 그 기록을 원작 차례대로 연출한다.

- CPU 걸은 뒤 0x4067b1(받은 명령): 대기·행동은 명령 방향(0x417957). 행동 대상 칸이 주체 칸이 아니면(범위 종류 5는 주체 칸) 커서(0x403c8e), 화면 확인 0x406ad9(효과 반경) → 창 밖이면 0x406b3a(반경 + 1) → 0x4147b3, 이어 하기 0x406a69. 소환은 바로 0x406d13. 되돌리기는 커서·대상 유닛 쪽 화면 이동 뒤 0x406d13. 사람 확정은 0x406d13을 바로 부른다.
- 소환 0x414059: 소환 스크립트 0x45f9ac(플래그 8, 대상 칸), 모으기 0x414397, 새 유닛 0x40f910(0x40f42f: 첫 빈 칸, 페이지 = 칸 × 0xe + 10, 숨김), 소환 그림 0xf·배치 0x10 → 페이지 0x2d5 묶음 7(키 −1·1), 0x402954. 되돌리기 0x406d13 종류 3: HP −10, 사라짐 0x41461a, 이어 하기 0x40536c(행동 뒤 흐름 없음).
- 행동 뒤 0x40623b: 정리 0x412843(HP < 1 네이티얼, 0x4128c8이 표시 객체를 지움), 타격으로 마스터가 쓰러졌으면(0x476b28) 마스터 사라짐(0x416129) 먼저, 마정석 점령 0x41481d(스크립트 0x45fd5c, 진영별 그림 0x11·0x13 배치 0x12·0x14 → 페이지 0x2f3 묶음 8, 0x32에서 0x4168ea → 0x40124c 소유 바꿈), 경험치 0x4147f2 → 0x4167a4(6틱 쉬고, 틱마다 +2(남은 것 3 미만이면 한 번에, 0x412cc9가 최대 레벨 100에서 멈춤), 6틱 쉼, 커서 0x403c8e), 0x40612c(마스터가 쓰러진 진영의 네이티얼 HP −10 뒤 모두 사라짐, 남은 네이티얼이 없으면 전투 끝 0x401ec3).
- 다음 차례 0x40536c: 정리, 차례 유닛(0x4129fb)에 커서, 시간 진행 0x4022d7(상태 이상이 다한 유닛 모습 0x412b50, MP 부족이면 소환 순번이 작은 네이티얼부터 사라짐 → 0x40536c 다시). 아니면 단계 0(0x40484b)과 화면 이동 0x4147b3(차례 유닛 표시 객체 칩 ((칩x + 1)·24, (칩y − 2)·12)를 가운데로, 0x4165bb가 틱마다 가로 먼저 48px씩) 뒤 0x40546d(차례 시작 지형 효과, 쓰러지면 사라짐 뒤 0x40623b).
- 음영 칸 0x76~0xe5(0x4027e3 어두운 판, 0x402954 밝은 사본)는 그 시각 팔레트로 한 번 계산해 둔다: 다음 차례 시작에 시각이 바뀌면 바탕 칸만 새 시각 색이다.

## 효과음 (③b-3e, `src/ui/battle/sound.ts`, 픽스처 `test/golden/sound.json`)

`PlaySoundA`(SND_ASYNC | SND_MEMORY) 하나로 낸다: 새 소리가 앞 소리를 끊고, SND_NOSTOP(0x10)이면 울리는 중일 때 내지 않고 FALSE. 옵션 0x503ff0 & 0x20이 꺼져 있으면 넷 다 아무것도 하지 않는다.

- 0x443d19(번호): 번호 0~13 → 리소스 0x47446c(DATA13 0x89~0x91, 0x95~0x99), 우선순위 0x4744a4(1 3 3 3 2 4 0 1 3 5 6 6 7 7). 버퍼 둘(0x483f20 + 0x80000 + i·0x20000)을 번갈아 쓴다: 지금 번호(0x4744e0)면 지금 버퍼(0x4cd6a4), 아니면 다른 버퍼에 없을 때(0x4744e4) 읽는다. 연출 효과음 중(상태 0x4cd6a8 = 2)이거나 지금 번호보다 우선순위가 낮으면 SND_NOSTOP(못 내면 그대로 끝). 내면 상태 1, 다른 버퍼였으면 바꾼다.
- 0x443e38(번호): 같은 버퍼 고르기, SND_LOOP | SND_NOSTOP, 내면 상태 3. 경험치 막대만 쓰고, 다음 효과음이 끊는다(0x443f9f는 전투를 나갈 때).
- 0x443f0a(리소스, 칸): 상태 2면 소리를 끄고(0x443f84, 상태 0) 칸(0x483f20 + 칸·0x20000)에 읽는다. 0x443f4b(칸): 늘 끊고 내며 상태 2.
- 연출: 스크립트를 걸 때 앞의 0x33(리소스, 칸)마다 미리 읽기(0x4157bf: 0x413852·0x413c45·0x4141fd·0x41481d), 0x34(칸)은 내기. 타격 0x40354b는 피해 행동(종류 0, 하위 0)이고 범위 종류 1·2면 칸 3. 연출 번호 2(0x413b45)는 0x45f8e0[유닛 +2 종류] → 칸 3, 모으기 0x415e18은 첫 틱에 칸 3. 마스터 소멸(0x41461a)은 0xd0088 → 0, 0xd0087 → 1, 0x416129가 9틱 뒤 0, 사라지기 전에 1. 소환(0x414059)은 0xd0086 → 0, 0x45faf4[마스터 +2 종류] → 3. 경험치 0x4167a4는 더할 때마다 레벨이 오르면 8, 세는 중이면 반복 6, 다 세면 7.
- 입력: 왼쪽 누름 0x403fb0(단계 1 차례 유닛 4, 2 멈출 칸 4, 3 방향 0, 4 대상 1·범위 중심 4, 5 칸 1, 6 1), 오른쪽 누름 0x4045ee(단계 1 유닛 4, 2·4·5·6 2, 3 0x405c74의 2, 7 2와 0x405e1d의 2), 메뉴 취소 0x405c74 2, 대기 0x405ce3·공격·마법 0x405d18·소환 0x405dcc 1(MP 알림이어도), 유닛 메뉴 되돌리기 0x41a9e5 1, 확인 0x405f13 1, 사람 입력 시작 0x4055cf 5. 시간 제한(0x407926: 10~13)은 프리 모드에 없다. 대화 상자·정보 창 효과음은 ③b-4.
