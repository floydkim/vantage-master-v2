# 장면 창(CEndingWnd)과 이벤트 스크립트

해독: ⑤c. 픽스처 `scene.json`(`pnpm oracle scene`).

## 창과 흐름

- 0x41becb(장면 6): 768 × 512 DIB(0x482dd8)와 팝업(0x421f0c, 프레임 위)을 만든다.
  - 메모리: 객체 표 0x482dc0 = 0x483f24, 지난 객체 0x483544 = +0x5140(80개 × 0x104), 팔레트 칸 0x48352c = +0xa280, 리소스 칸 0x483540 = +0xa400.
  - 0x483528(ED 번호) = 0, 가상 시계 0x483404·글 시계 0x482df8·16ms 카운터 0x503dec = 0x34bc0.
  - 0x41c193(스크립트 읽기) 뒤 48ms 콜백 = 0x41d843.
- 0x41c193:
  - 0x41c111: DIB를 색 10으로, 팔레트 공통 1·2, 0x41b166(0, 0, 0, 0, 0, 0xec), 전체 다시 그리기.
  - 객체·팔레트 칸 비우기. 팔레트 칸 0 = 공통 2(0x4801a8, 0x44색, 처음 칸 0x32).
  - 스레드 하나(0x482e00), 자르기 사각형 (0, 0, 768, 512).
  - 스크립트:
    - 종류 0~5는 0x460168[종류] = DATA08 0~5다.
    - 종류 6은 0x483528 = 0이면 0x460180[진영 0 +0x9c] = DATA09 0~0x1a(마스터 ED)다.
    - 그 뒤 0x4601e8[0x483528] = DATA09 0x1b~0x34 26편이다.
  - 첫 스텝을 바로 돈다(0x41d843).
- 0x41d7e8(스크립트 끝):
  - 0x483528 + 1.
  - 종류 6:
    - 0x1b 미만이면 다음 ED다.
    - 0x1b면 보고서(0x41c2f2)다.
    - 그 뒤는 창 닫고 타이틀(0x425fa0)이다.
  - 종류 0~5는 창을 닫고 월드(0x4516f4)로 간다.
- 장면 창은 클릭을 받지 않는다. 보고서 단추만 받는다(0x421f85 마우스 위, 0x421fc8 클릭).

## 스크립트의 글(명령 0x29)

- 장 사이 장면(DATA08 0~5) 글은 영문판에서도 Shift-JIS 일본어다.
  - 예: 종류 0의 `《%M》`, `《メルレット》`, `…%Mさん。`(대사)
  - 원작 영문판은 이것을 TextOutA로 그려 서양 코드 페이지에서 깨진 글자가 나왔을 것이다.
  - 리메이크는 원문 모드에서 2바이트 글자를 Shift-JIS로 풀어 일본어 고딕 글리프로 그린다(`src/i18n/hangul.ts` `setWideGlyphs`, ⑥a). 한 글자로 풀리지 않는 것(영문 글의 `\xa1\xa1`·`\xa1\xa4`)은 빈칸이다. 시험(오라클 대역)은 글리프를 켜지 않아 2바이트가 빈칸이고 CRC는 같다.
  - 한국어 모드에서는 한국어판 DATA08의 한국어 글이다(⑤e).
- 엔딩(DATA09 ED) 글은 영어다. 예: ED 9의 ` <%M> `, ` <Women> `.
- `%M`은 진영 0 이름(이름 안의 `%M`·`%%`는 다시 풀지 않음), `%%`는 %다.

## 스케줄러 0x41d843(48ms)

- ED 번호 0x1b(보고서)면 0x41d543: 페이드 → 단추 깜빡임(2틱마다 프레임 + 1, 8프레임)이다.
- 그 밖이면 객체를 지난 객체(0x483544)에 복사한 뒤 아래를 반복한다.
  1. 스레드마다 해석기 0x41da0d를 한 번 돈다.
  2. 끝 플래그(1)인 스레드는 뺀다. 남은 스레드가 모두 '끝내도 됨'(2)이면 0x41d7e8로 가고 돌아온다.
  3. 객체를 갱신한다(0x41f1fa).
  4. 가상 시계 −3.
  - 16ms 카운터 ≤ 시계 − 0x3f인 동안 되풀이한다(늦은 틱 따라잡기).
- 그다음:
  - 다시 그릴 사각형을 정하고 그린다(0x41fa90).
  - 번쩍임이 진행 중이면 색 표를 다시 쓰라는 플래그를 켠다(0x41b421 → 0x421a76).
  - 플래그가 켜져 있으면 색 표를 다시 쓴다.
  - 사각형을 화면에 낸다(0x421eb9).

## 스레드(0x18바이트, 0x482e00)

| 칸 | 뜻 |
|---|---|
| +0 | 명령 자리 |
| +4 | 잠 틱(0x22, 0보다 크면 이번 스텝은 −1만) |
| +8·+0xc | 되풀이 남은 수·되풀이 시작 자리(0x2f·0x30) |
| +0x10 | 플래그: 1 끝, 2 끝내도 됨 |
| +0x14 | 객체 번호 표(0x100 이상인 객체 번호는 이 표의 [n − 0x100]) |

## 그리기

- 0x41fa90: 객체마다 이번·지난 화면 사각형을 비교해 다시 그릴 사각형을 모은다(0x421c6d). 깊이로 차례를 정렬한다.
- 0x41ff02: 사각형마다 색 10으로 지운 뒤, 보이는 객체를 차례대로 그린다(0x420287).
- 0x420287 네 갈래:
  - 배치표(플래그 4)·1:1이면 0x42039c다. 칩 4열 × 8줄이고, 0x7ff는 빈 칩이다.
  - 배치표·크기 바꿈이면 0x420c36이다.
  - 그림·1:1이면 0x4208d4다.
  - 그림·크기 바꿈이면 0x4213d0이다.
  - 넷 다 무늬 비트가 켜진 픽셀은 건너뛴다. 플래그 2면 0x10은 투명이다.

## 보고서 TBREP(0x41c2f2)

- 바탕 DATA09 0x7b(+ 0x6f), 팔레트 0x7c, 단추 그림 DATA00 0x16(페이지 0)이 있다.
- 세 쪽(0x482dc8)이다. 통계는 0x482dc4 = 블록 +0xd78이다.
  - 0(0x41c62f): 날짜·시각, 마정석, 사용 MP, 마스터 행동, 공격·마법·소환 횟수, 네이티얼 경향(원소 넷의 비율, 합 0이면 1로 나눔)
  - 1(0x41d077): 네이티얼 24 이름·횟수·SAT·평균(횟수 0이면 0). 가진 것은 색 0xb, 아니면 0x79
  - 2(0x41d3c6): 마법 6 이름·횟수
- 단추:
  - 앞(0x240~0x26f, 0x1d0~0x1e7)은 쪽 0에서 안 된다.
  - 다음(0x288~0x2b7)은 쪽 2에서 누르면 끝(0x41d7e8)이다.
